# Bank Application

## Overview
This is a **Java-based Bank Account Management System** that allows users to create and manage multiple bank accounts, including **Savings** and **Current** accounts.  
It demonstrates key Object-Oriented Programming (OOP) concepts like **inheritance, abstraction, interfaces, and polymorphism**.

---

## Features
- Create multiple accounts (Savings or Current) per user  
- Deposit money into accounts  
- Withdraw money with account-specific rules:
  - Savings Account: withdrawal limit of 20,000  
  - Current Account: unlimited withdrawal up to balance  
- Track account balances and account numbers  
- Remove accounts from a user  
- Supports multiple users
